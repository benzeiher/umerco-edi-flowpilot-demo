# Service Catalogs

This directory contains JSON service contract catalogs that describe the input and output signatures of built-in webMethods services and custom domain services. AI skills use these catalogs to resolve valid service names and pipeline variables during FSL generation.

## Structure

| Folder | Description |
|---|---|
| [`wm-service-catalog/`](wm-service-catalog/) | Built-in webMethods Integration Server service contracts |
| [`custom-catalog/`](custom-catalog/) | Project-specific or domain-specific custom service contracts |
