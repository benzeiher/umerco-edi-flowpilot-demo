# Flow Examples

This directory contains working `.flow` FSL examples for webMethods Flow Services. The examples are organized into three tiers to help you identify a reference for your use case.

## Tiers

| Folder | Description |
|---|---|
| [`basic/`](basic/) | Fundamental flow steps and simple arithmetic services |
| [`intermediate/`](intermediate/) | Multi-step service composition and pipeline transformations |
| [`advanced/`](advanced/) | Complex patterns, nested control flow, and production-ready designs |
