# Basic Flow Examples

This directory contains basic `.flow` examples that demonstrate fundamental FSL constructs, including flow steps such as MAP, IF/ELSE, LOOP, WHILE, BRANCH, SWITCH, TRY-CATCH, and simple arithmetic services.

## Structure

- **`FlowSteps/`** — One example for each flow control step, including IF, LOOP, WHILE, BRANCH, SWITCH, TRY-CATCH, REPEAT, EXIT, BREAK, CONTINUE, DO-UNTIL, and TRY_FINALLY
- **`Math/`** — Simple arithmetic services for integer addition, subtraction, multiplication, and division
